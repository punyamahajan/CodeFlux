# Expense Tracker

This is a Streamlit app that helps you track your expenses. It allows you to add expenses with an amount and category, displays the total expenses per category, and saves the data to a JSON file.

## How to Run the Expense Tracker

1. **Install Dependencies**:
   ```
   pip install streamlit
   ```

2. **Run the App**:
   ```
   streamlit run main.py
   ```

3. **Adding Expenses**:
   - Open the sidebar and click the "Add Expense" button.
   - Enter the amount and category of the expense and click the "Add" button to submit.

4. **Viewing Total Expenses by Category**:
   - The main page displays the total expenses for each category.

5. **Saving and Loading Data**:
   - The app saves the expense data to a JSON file on your local machine.
   - Data is loaded on startup.

## Getting Started

1. Run the app using the command above.
2. Navigate to the sidebar and click "Add Expense".
3. Enter a new expense and submit it.
4. Observe the total expenses per category on the main page.

The app ensures that all data is preserved across sessions, making it easy to track your expenses continuously.
